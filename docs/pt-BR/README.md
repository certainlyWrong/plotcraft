# Documentação do Plotcraft

Esta documentação registra a visão do produto e os conceitos que devem orientar sua evolução. Ela distingue intenções de recursos que já existem no aplicativo.

O idioma desta documentação é português. As regras de idioma descritas nos documentos se referem à interface do aplicativo.

## Vocabulário

- **Projeto**: unidade principal de trabalho, que representa uma história e reúne seus metadados e materiais de desenvolvimento.
- **Área de projetos**: tela de entrada para criar, localizar e organizar projetos.
- **Editor**: espaço de trabalho de um projeto. A escrita é uma parte dele, não a definição inteira do produto.
