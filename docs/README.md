# Plotcraft documentation

This documentation records the product vision and the concepts that should guide its evolution. It distinguishes intentions from features that already exist in the app.

This documentation is written in English, with translations in [Portuguese](pt-BR/README.md) and [Spanish](es/README.md). The language rules described in the documents refer to the app's interface.

## Vocabulary

- **Project**: the main unit of work. It represents one story and gathers its metadata and development material.
- **Projects area**: the entry screen to create, find and organize projects.
- **Editor**: a project's workspace. Writing is one part of it, not the whole definition of the product.
