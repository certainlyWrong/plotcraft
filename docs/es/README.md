## Vocabulario

- **Proyecto**: la unidad principal de trabajo. Representa una historia y reúne sus metadatos y su material de desarrollo.
- **Área de proyectos**: la pantalla de entrada para crear, buscar y organizar proyectos.
- **Editor**: el espacio de trabajo de un proyecto. La escritura es una parte de él, no la definición completa del producto.
